# Project maintenance and feedback

VEXT is maintained by SoDianel / Dianel Records. External code contributions and
pull requests are not accepted. Development priorities and releases are managed
by the maintainer.

Bug reports and feature suggestions are welcome through the issue templates.
Include the VEXT version, Windows version, reproduction steps and relevant logs.
Remove personal paths, plugin inventories, credentials and other private data.
Report security problems privately as described in [SECURITY.md](SECURITY.md).
The [Code of Conduct](CODE_OF_CONDUCT.md) applies to public interactions.

Source builds are documented in [LOCAL_SETUP.md](LOCAL_SETUP.md).
VEXT remains free software under [GPL-3.0-or-later](LICENSE).
