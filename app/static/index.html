Pending actions are proposed but not yet applied. Nothing on disk has changed for these. "Apply" is the only step that touches a real file.

Duplicates

Same plugin available in a lower-priority format (CLAP > VST3 > VST2) or duplicated across install locations (64-bit vs 32-bit, older vs newer Waves version), vendor-verified before grouping. Nothing is deleted automatically. Propose an action, then apply it explicitly from Pending (moves the file to quarantine; see the Quarantine section to restore or permanently delete it afterwards).

Flagged

Corrupted files, incomplete installs, and Pro Tools/AAX plugins (Pro Tools isn't part of this workflow).

Plugins sitting loose directly in a format folder (e.g. Common Files\VST3\) instead of their own <Vendor>\ subfolder. Handy for spotting a newly installed plugin you didn't organize at install time. FL-Native, Waves, and AAX are excluded, since none of those use a vendor-subfolder layout. Nothing is moved automatically. Propose, then apply from Pending.

Plugins with no vendor. An AI can look each one up, one by one or a group at a time. Its answer waits here until you apply it.

Vendor websites and status

Vendors missing a website, a status or a KVR / Equipboard page. A vendor is one record shared by all its plugins, so applying one updates every plugin of that vendor. The two database pages are what remains of a vendor that has closed.

The vendor of these plugins was guessed from folder names or installers, not read from the plugin itself. Confirm a guess as it is, or let an AI verify it first. A confirmed vendor is kept on rescans.

Two or more real plugins share this exact name. The vendor was deliberately left unresolved rather than guessed. Verify by opening the plugin.

Plugins with no known effect/synth type. When FL Studio's own plugin database knows a plugin it reports the type directly, shown as a one-click suggestion. An AI can also decide, one by one or a group at a time. This only edits metadata; no file is touched.

Plugins with no category. An AI can choose categories for each one, one by one or a group at a time. Its answer waits here until you apply it.

Plugins missing any of three links: the official store page (never a reseller such as Plugin Boutique), the KVR Audio database page and the Equipboard database page. The database pages matter most for plugins whose vendor is gone. An AI can look all three up in one go, one plugin at a time or a group at a time. Only links a plugin doesn't have yet are filled in; an existing link is never replaced. When the AI looks and finds no page on a site, applying its answer marks that link as None (for example "No KVR"): that is settled, not missing, and the plugin leaves this list once all three are a link or None. You can also mark a link None yourself with "Enter manually". A grey "KVR ?" means never looked at.

Plugins without a picture. A plugin that opens in the Playground can be captured: VEXT takes a picture of its own window. For the ones that can't open here (FL Studio's own plugins, unlicensed or 32-bit ones, plugins that fail to load), VEXT can look for one on the web: it reads the plugin's store and KVR pages itself (their share image, screenshots and video thumbnails), and an AI looks further when those have none (the vendor's pages, manuals, partner news, official videos; a store's product image as a last resort). Each picture is downloaded and checked, then waits here labelled "Likely" or "Possible" with the reason: open Choose picture…, pick the one you like and Apply. Nothing becomes a plugin's picture before that.

Items moved here are never permanently deleted automatically. Restore them to their original location, or permanently delete them yourself (irreversible). Quarantine is the recoverable "trash" tier. If you delete a quarantined file yourself outside this app, hit "Sync" in the Scan section (or just scan again) and its entry here disappears on its own.

Appearance

        
Follow the system setting by default, or pick light or dark for this app.

        

          
          
          
        

      


      

        
Visual effects

        
Animations across the app, the 3D Scan button and the moving charts on the Dashboard. They are light
          and need no graphics card; turn them off on a slower PC and everything stays, without motion. Auto turns them off
          when Windows asks for less motion (Settings > Accessibility > Visual effects > Animation effects); On keeps
          them even then.

        

          
          
          
        

        

      


      

        
Paths and settings

        
Changes take effect on the next scan, not retroactively.

        

      


      

        
Quarantine older copies

        
After each scan, VEXT proposes quarantine for copies that a better one supersedes.
          Ranking: CLAP over VST3 over VST2 over VST, and 64-bit over 32-bit. Proposals are only proposals. Each one
          is confirmed in Actions > Pending before any file moves.

        
      

    


    
    

      
Every folder the scanner looks in. "Organizable" controls whether a loose plugin in that folder
        (not yet in its own vendor subfolder) gets proposed for reorganization. Leave it off for fixed-layout formats like
        FL-NATIVE, WAVES and AAX. Removing a standard location is undone from "Removed built-in paths" below.
        FL Studio's own folders are set in DAWs.


      

        
Format folders

        
The folders every plugin format is scanned from, 32-bit and 64-bit. They are detected on this PC
          the first time, can be changed here, and can't be removed. "Reset" returns a path to what was detected.
          Turn off "Scan" to skip a folder without losing its path.

        

      


      

        
Other standard locations

        
Folders for other installed products, such as Waves. These can be edited or removed.

        

      


      

        
Custom paths

        
Any other folder to scan, for example another product's plugin folder. Custom paths are
          scanned exactly like the standard ones.

FL Studio

        
FL Studio is found automatically from the Windows registry; set a folder only if it lives somewhere
          unusual, or to point at another version. Auto-detect clears your folder and detects again. FL Studio Sync in the
          sidebar and the FL Cloud options only show while FL Studio is installed.

        

      


      

        
FL Studio plugin database

        
Where FL Studio keeps what it knows about each plugin (Presets\Plugin database\Installed).
          VEXT reads it for the "FL" badge and FL's own plugin names and types, and FL Studio Sync files plugins inside it.
          Changes take effect on the next scan.

        

      


      

        
FL-NATIVE plugin folders

        
FL Studio's own stock plugins are scanned from these folders. They follow the FL Studio folder above.

AI agents (Codex from OpenAI, Claude Code from Anthropic, Antigravity and Gemini CLI from Google)
        can research a plugin's vendor, links, category, description and picture, then VEXT proposes the result for review.
        Nothing is applied without your confirmation. Each agent signs in on its own, so VEXT never sees your credentials.


      

        
Where the AI actions are

        
The AI actions live in Actions > Metadata, next to the metadata they fill: Missing vendor,
          Inferred vendor, Missing type, Missing categories, Missing links and Missing picture. Each lists the plugins that lack it, with
          Investigate buttons for a single plugin or a whole group. This pane only sets the AI agents up.

AI agents

          

        

        
Install and sign in to each agent you want to use. Claude runs on your Claude subscription, Codex on
          your ChatGPT plan, Antigravity on your Google account. An agent that would bill an API key (Gemini CLI) is only used
          after you allow it on its card. When more than one agent is ready, every investigation asks which one to use. All
          agents get the same prompt. Models and effort levels come from each agent itself where it can list them, so only
          valid choices are offered.

        

        

      


      

        

          
Research prompt

          

            
            
            
          

        

        
Change how the AI searches and what it should weigh. Keep {name} and
          {category_list} in the prompt. The other tokens are filled in per plugin:
          {format}, {vendor}, {store_url}, {host_path}.
          VEXT always asks the AI for the same structured answer, so the format stays valid whatever you write here.

Ignored plugins

        
Plugins removed from the main catalog with "Ignore" (in a plugin's details or its ⋯ menu). Future
          scans skip these files entirely. Un-ignoring doesn't bring one back by itself. The next scan re-discovers it normally.

        

      

    


    
    

      
Plugin-like files found outside the known scan folders. This only populates after turning on
        "Full C: scan" in the Scan section and scanning. Never enriched, never part of dedup or cleanup. Fix it yourself
        (move the file into a known folder, then scan again), permanently delete it (no quarantine step, since these were
        never tracked), or ignore it.

          Add that folder here and it'll be scanned like any other known location from now on, with full vendor and
          category resolution, dedup, and quarantine or reorganize.

Registry cleanup

        
Deleting a plugin here removes only its file. Windows keeps a separate "Programs and Features"
          record of what its installer registered, so a later install can still report the format as "already installed".
          Search by vendor and or name to find and remove those leftover records. Registry only. No files are touched.
